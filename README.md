# x24humanai.com — the public door

This repository serves one page: the public invitation of the **X24 Human-AI Exchange**, at [x24humanai.com](https://x24humanai.com).

It is a door, not the work. There is no live feed here, no dashboard and no ledger. What the project publishes, it publishes on purpose, and corrects forward.

## Why the source is public

The page claims that this project's record is checkable. A front page whose history nobody can inspect would be the first place that claim fails. Every change to the invitation is a commit here: what changed, when, and why.

Corrections are forward acts. Nothing is silently rewritten; a wrong sentence is replaced by a commit that says it was wrong.
